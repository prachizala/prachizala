## 4. Technical Interview Cheatsheet (Quick Talking Points)

### Q1: "Walk me through how you handled multi-tenancy in ProjectPilot."
* **Answer**: *"In ProjectPilot, every organization/freelancer has a unique `tenant_id`. In our SQLAlchemy models, all entity tables (`clients`, `projects`, `invoices`, `tasks`) have a foreign key to `tenant_id`. Every authenticated API request decodes the user's `tenant_id` from the signed JWT payload. Database queries explicitly filter by `tenant_id == current_user.tenant_id`. We verified this with dedicated multi-tenant boundary tests, ensuring that Client A cannot query or mutate Client B's records even with direct ID manipulation."*

### Q2: "Why did you use PyMuPDF for invoice generation rather than a headless browser like Puppeteer?"
* **Answer**: *"Headless browsers introduce significant memory overhead (150MB+ per process) and slow startup latency. By contrast, PyMuPDF generates native vector PDFs with sub-25ms compilation speed, negligible RAM footprint, crisp text rendering at any zoom level, and guaranteed file handle closure in Python context managers."*

### Q3: "How does the Safety Sentinel in MindTrack operate safely?"
* **Answer**: *"For user privacy, journal text is encrypted with AES before database persistence. However, during active entry creation, our in-memory Safety Sentinel evaluates distress keywords and acute emotional crisis markers. If critical thresholds are crossed, the API intercepts the response to attach official emergency resources (such as India's 24/7 Tele-MANAS 14416 helpline) accompanied by mandatory non-medical disclaimers, ensuring ethical software responsibility."*

### Q4: "How does StudyBuddy RAG prevent context fragmentation?"
* **Answer**: *"Naive text splitting cuts paragraphs arbitrarily, causing split sentences and lost context. We implemented a sliding-window text chunker with a 15% overlapping boundary. Each chunk preserves source page metadata. When a query is made, we compute vector cosine similarities across chunks and extract only high-relevance blocks into the context payload, keeping retrieval latency below 80ms."*
